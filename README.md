# AI-Content-Generator
AI Automation Generator using Google Gemini API, Python, and Google Colab.

## Features

- Generate AI workflows
- Custom prompts
- Fast responses

## Tech Stack

- Python
- Google Gemini API
- Google Colab

## Setup

1. Get a Gemini API key.
2. Add it to Colab Secrets as `API_KEY`.
3. Run the notebook.
